## Cross-checks

- ☐ Name on DL matches name on Aadhaar
- ☐ Name on DL matches name on PAN
- ☐ Name on DL matches name on bank account
- ☐ DOB on DL matches DOB on Aadhaar
- ☐ Address on DL or Aadhaar matches current residence (within reason)
- ☐ Vehicle number on RC matches vehicle number on Insurance, Permit,
  Fitness, PUC

If any cross-check fails — STOP and refer to the SOP Step 3 process.
